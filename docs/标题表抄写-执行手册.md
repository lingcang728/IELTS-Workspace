## 一、这批题是什么

它们的答案是罗马数字（`iv`、`viii`），那是剑桥给 **List of Headings** 小标题表的编号。但**那张表从未被抽取出来**——考生被要求"给每段选一个小标题"，底下却什么都没有。

```
cambridge-10-test-2-reading  Q1
  说明：Reading Passage 1 has seven paragraphs, A-G. Choose the correct heading…
  答案：iv
  选项：（空）      ← 那张 i–viii 的标题表不见了
```

和上一轮的选项不同：**标题表每篇文章只印一张**，同一篇里所有小标题题共用它。所以工单是**按文章**发的——你抄一张 `i`–`viii` 的表，一次答完 8 到 10 道题。176 道题因此塌缩成 47 次翻页。

## 二、你要做什么

1. 读 `data-dev/repair/headings-tasks/<taskId>.task.json`。关键字段：
   - `questionNumbers`：这篇里靠这张表作答的题号
   - `romanKeysUsed`：**答案实际用到的罗马数字**（闸门会拿它卡你）
   - `groups`：哪些组共用这张表
2. 打开 `images` 里的页面图，找到那个 **List of Headings** 方框。
3. **照抄整张表**，从 `i` 开始，一条不漏。
4. 写成 `data-dev/repair/headings-tasks/<taskId>.answer.json`：

```json
{
  "taskId": "cambridge-14-test-2-reading-h-p3",
  "headings": [
    "The productive outcome of a wrong assumption",
    "A description of a new approach",
    "Reasons for the decline of an industry"
  ]
}
```

数组按 `i`、`ii`、`iii`… 顺序；也可以写成 `{"i": "…", "ii": "…"}` 对象。

5. 自检通过后提交：

```
python scripts/repair/78_write_headings.py --task <taskId> --check-only
python scripts/repair/78_write_headings.py --task <taskId>
```

（python 用 `G:/python/python.exe`）

## 三、闸门会怎么查你

全单拒收，五道闸：

1. **taskId 匹配。**
2. **编号从 `i` 起连续**——剑桥连续编号，跳号说明抄漏了一行。
3. **每条都有文字、互不重复、且文字不能就是它自己的编号。**
4. **标题是短语不是段落**——超过 160 字的多半是把正文抄进来了。
5. **答案用到的每个罗马数字都必须在你交的表里。** 一篇答案里出现了 `ix`，而你的表只到 `viii`，那要么抄漏了一条，要么抄的根本不是这篇。

第 5 条是这轮的硬闸，和上一轮"答案字母必须在选项里"是同一个道理——**答案键已经从书末印刷答案页核对过，它是一个独立于你的第二证人。**

自测过五种失效模式（合法 / 表太短缺编号 / 文字就是编号 / 两条重复 / 整段正文），全部按预期拦截。
