## 一、这批题是什么

它们的答案是一个字母（说明印刷页上给了选项让考生选），但**选项列表从未被抽取出来**——题上没有、组上也没有。考生看到题干，底下什么都没有，根本无法作答。

```
cambridge-10-test-1-listening  Q22
  答案键：A          ← 印刷答案页确认过的
  选项：  （空）      ← 从未被抽出来
```

全库 413 道，是上一轮把 984 处答案键换成书末印刷答案之后**暴露**出来的：旧键错得恰好能和错题型互相圆场，两边一起藏在门后面。

它们在题库里表现为 413 个单题组，那是导入器的产物，不是书的排版——印刷页上通常好几道挨在一起。所以工单**按页聚簇**：一单平均 2.4 题，你读一页，把这页上的都答了。

## 二、你要做什么

对每个工单：

1. 读 `data-dev/repair/option-tasks/<taskId>.task.json`。里面 `questions` 列出本页要补的题：题号、题干片段、`answerLetters`（答案字母）、题型、组说明。
2. 打开 `images` 里的页面渲染图。
3. **照抄印刷页上那道题的完整选项列表。**
4. 写成 `data-dev/repair/option-tasks/<taskId>.answer.json`：

```json
{
  "taskId": "cambridge-14-test-2-listening-o0034",
  "questions": {
    "21": ["it is in a convenient location", "it has a large car park", "it is open at weekends"],
    "22": {"A": "reading", "B": "swimming", "C": "cycling", "D": "running"}
  }
}
```

数组按 A、B、C… 顺序，或者用 `{标签: 文字}` 对象，两种都收。

5. 自检通过后提交：

```
python scripts/repair/76_write_options.py --task <taskId> --check-only
python scripts/repair/76_write_options.py --task <taskId>
```

（python 用 `G:/python/python.exe`）

## 三、闸门会怎么查你

全单拒收，六道闸：

1. **题号覆盖**——正好是本工单的那几题，不多不少。
2. **至少两个选项**——"只有一个选项的选择题"不成立。
3. **每个选项都有文字，且同题内不重复。**
4. **选项文字不能就是它自己的字母。**`{"A": "A"}` 是地图题的诚实建模方式，但**本轮 413 题里一道地图题都没有**，所以出现这个只说明没真的看页面。
5. **标签必须 A、B、C… 连续**——印刷题不会跳号成 A、C、D。
6. **答案字母必须在你交的选项里。**

第 6 条是这一轮真正的硬闸，也是上一轮做不到的：上一轮的答案键本身就是坏的。现在键是从书末印刷答案页抄下来并逐条机检过的，等于给了你一个**独立的第二证人**。抄错了题、少抄一个选项、或者凭空编一个短列表——都不会包含那个字母，当场拒收。

自测过六种失效模式（合法 / 少抄到缺答案字母 / 文字就是字母 / 只给一个 / 两个重复 / 漏题），全部按预期拦截。

## 四、纪律

- **不许猜。** 页面上没印的一个字都不许写。
- **看不清**：工单给了 `pdf` 和 `pdfPagesZeroBased`，可以自己重渲更高 DPI。仍然不行就**不提交这一单**，在汇报里说明是哪一单、哪几题、为什么。宁可少一单，不要错一单。
- **答案字母对不上时先怀疑自己抄错了题**。键是核对过的；真觉得是键错了，不提交，单独报出来。
- **不要碰 `fixtures/cambridge/`**。提交只走 `76_write_options.py`，它写进 `fixtures/overlays/`，后续由 `40_apply.py` 统一落地。
- **不要跑** `40_apply.py`、`69 --apply`、`verify_cambridge.py --update-baseline`。并发跑会互相覆盖。
- 只做分给你的工单。
