# 发布说明

发布脚本从本节抽取对应版本的正文，写入 `latest.json` 的 `notes`。

## 1.3.7

交卷防抖不再把已提交会话盖回进行中；听力模考禁止快进；窄窗口不再藏音量和 Display。迁移旧数据改为改名备份而不是整目录删除。错题本支持多选集合核对，计时只在 10:00 / 5:00 节点闪烁。工作台卡片齐高，练习目录不再套一层滚动条。

## 1.3.6

练习考场深色改为与工作台相同的蓝灰，不再用棕灰。练习可「Save and exit」保留进度离开；模考「Leave test」需二次确认，同样保留进度，不算交卷。

## 1.3.5

恢复工作台原来的蓝色外壳，撤回 1.3.4 的纸感暖色。题库棋盘、选择题、导入和性能改动保留。

## 1.3.4

题库入口、选择题与工作台外壳：
1. 练习/模考列表按剑桥册棋盘展示（剑 4–21 × Test 1–4），不再每页 6 条平铺；官方样题按真实 `official_sample` 选取，不再把排序第一套冒充官方。
2. 选择题：Choose TWO/THREE 改为共享选项勾选（模考 checkbox，练习卡片）；Mock 选中行有可见高亮，不影响官方浅色考场。
3. 工作台外壳回到 kami 纸感暖色（浅色纸 + 朱砂，深色暖近黑），与官网同族；侧栏与标题区收紧，分析页去掉口语空环和重复趋势图。
4. 导入支持选择/拖入 JSON 文件，失败留在导入页提示，不再把整应用打成错误屏；设置页展示真实数据目录。
5. 性能：题库索引只缓存路径、按需读卷；考场倒计时与听力进度不再每 250ms 重绘整张试卷；生产构建关闭 sourcemap。

## 1.3.3

系统级稳定性、评分引擎与考场 Runtime 全面升级：
1. 评分引擎重构：修复作答对象解包逻辑，彻底解决会话持久化后历史考卷重判为 0 分的缺陷；多选题支持任意顺序作答正确匹配；全面汉化评分错误提示。
2. 考场 Runtime 增强：长文渲染与作答映射加入高精度缓存，消除倒计时频繁更新时的渲染风暴；支持考场左右双栏自由拖拽调整比例；音频离开考场时自动彻底释放硬件解码缓冲；防止倒计时并发交卷重入。
3. 数据容灾与系统防护：会话主文件读取损坏时支持同名备份文件自动无损回滚自愈；防范 Windows 设备保留名渗透；生词本与错题本重考状态流转与非 ASCII 标识符自适应哈希。
4. 视觉隔离与网络边界：考场专属划选、焦点圈与控制按钮样式与工作台外壳彻底隔离；构建系统集成发布卫生与版本一致性门禁；修复官网下载链接版本映射。

## 1.3.2

听力页改成剑 4–20 棋盘：已添加绿色打勾，未添加灰色。选择文件夹支持一次多选。

## 1.3.1

听力导入改为严格四段制：只接受剑 4–20 每套 Part/Section 1–4，去掉整轨校准。旧整轨绑定标为「需要重新导入」，不删除用户文件。

练习考场可跟随工作台或固定浅色/深色；模考仍是官方浅色，并保留高对比和米色。已提交的历史不会因重考删除。提交保存失败会留在考场并允许重试。听力播放位置每 5 秒及切 Part、失焦、关闭前落盘。

自定义 JSON 导入限制体积、题量和相对资源路径；收紧 CSP 与本地资源范围。

## 1.3.0

内置剑桥题库（阅读/写作开箱即用），Listening 音频改为本机导入；安装版数据目录改为 LocalAppData。
