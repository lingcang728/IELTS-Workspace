# 发布产物 (Release Binaries)

本目录保留 **IELTS Workspace 1.0.0** 的历史构建。最新签名安装包、便携版与自动更新清单请从 [GitHub Releases](https://github.com/lingcang728/IELTS-Workspace/releases/latest) 下载。

## 文件列表

| 文件名 | 类型 | 说明 |
| :--- | :--- | :--- |
| **`IELTS_Workspace_1.0.0_x64_setup.exe`** | Windows 历史安装包 | 1.0.0 安装程序；不含应用内自动更新 |
| **`IELTS_Workspace.exe`** | Windows 历史便携版 | 1.0.0 单文件版本 |

## 系统要求

- **操作系统**：Windows 10 / Windows 11 (64-bit)
- **运行依赖**：基于 WebView2（Windows 10/11 系统通常已自带）
