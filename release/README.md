# 发布产物 (Release Binaries)

本目录包含 **IELTS Workspace** 最新构建的 Windows 桌面端可执行文件与安装程序，方便直接下载与分发使用。

## 文件列表

| 文件名 | 类型 | 说明 |
| :--- | :--- | :--- |
| **`IELTS_Workspace_1.0.0_x64_setup.exe`** | Windows 安装包 (推荐) | 运行后将自动安装程序并创建开始菜单/桌面快捷方式 |
| **`IELTS_Workspace.exe`** | 单文件可执行程序 | 独立免安装版，直接双击即可运行 |

## 系统要求

- **操作系统**：Windows 10 / Windows 11 (64-bit)
- **运行依赖**：基于 WebView2（Windows 10/11 系统通常已自带）
